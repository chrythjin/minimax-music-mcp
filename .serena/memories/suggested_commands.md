# Suggested Commands

Windows PowerShell environment. Common commands:

- Install deps: `npm install`
- Build TypeScript: `npm run build`
- Run tests: `npm run test`
- Watch build: `npm run watch`
- Check git state: `git status --short`

Use OpenCode file tools for reading/editing/searching when possible. For terminal commands, prefer PowerShell-native syntax and quote paths containing spaces, e.g. `"C:\NEW PRG\minimax-music-mcp"`.
